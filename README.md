# Continuity
A context manager for keeping track of long-running projects so you dont have to.

URL: [https://continuity-archive.onrender.com/](https://continuity-archive.onrender.com/)

### What it does
It records what you do, learn, decide, and discover while working on a project.  

When you return after days, weeks, or months, Continuity helps you quickly understand where you left off.

### How it's supposed to work
1. Everyday you make an Entry of a specific project, like a diary.
2. The Entry is timestamped and useful features are automatically extracted from it.
   - These features include:
      * Current goal
      * Current progress
      * Problems faced
      * Decisions made
      * Things learned
      * Unresolved questions
      * Next actions
      * etc
3. Features of the current Entry are compared with the prevoius Entry, and the context of the project is updated.
4. The project Context is a large string of text that includes every usefull piece of information about a project.
5. The system keeps track of how frequently each project gets updated.
6. If the user returns to a project after an unusually long time, the project's Context is used to remind the user of where they left off.
7. If a new Entry includes a problem the user has faced before, the system notifies the user with the solution they used prevoiusly.
8. The feature list will only increase over time, as it is a hobby project.
